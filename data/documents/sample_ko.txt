Senzing은 세계 최고 수준의 엔티티 해소(Entity Resolution) 엔진입니다. 수십억 개의 레코드에서 동일한 실체를 식별하고 통합할 수 있으며, 실시간 스트리밍과 배치 처리를 모두 지원합니다. Senzing SDK는 gRPC 프로토콜을 통해 다른 시스템과 통합할 수 있습니다.

strwythura는 구조화된 데이터와 비구조화된 데이터를 결합하여 엔티티 해소 지식 그래프를 구축하는 Python 프레임워크입니다. Context Engineering 기법을 활용하여 특정 도메인에 최적화된 AI 애플리케이션을 지원합니다. MIT 라이선스로 제공되어 상업적 사용이 가능합니다.

LanceDB는 Lance라는 오픈소스 컬럼형 데이터 포맷 위에 구축된 서버리스 벡터 데이터베이스입니다. 전문 검색, 벡터 검색, 하이브리드 검색을 지원하며, Python 데이터 과학 도구와 잘 통합됩니다. 임베딩의 효율적인 저장과 검색을 제공합니다.

spaCy는 산업용 강도의 자연어 처리(NLP) Python 라이브러리입니다. 빠른 토큰화, 품사 태깅, 개체명 인식(NER), 의존 구문 분석 등을 제공합니다. 한국어 모델(ko_core_news_lg)을 통해 한국어 텍스트 분석도 지원합니다. GLiNER은 spaCy를 확장하여 학습 없이도 커스텀 엔티티 타입을 추출할 수 있는 제로샷 NER 기능을 제공합니다.

DSPy는 언어 모델을 프로그래밍하기 위한 프레임워크입니다. 시그니처, 모듈, 옵티마이저를 제공하여 LLM과의 구조화된 상호작용을 가능하게 합니다. GraphRAG 파이프라인에서 DSPy는 프롬프트 엔지니어링과 응답 생성 단계를 관리합니다.
