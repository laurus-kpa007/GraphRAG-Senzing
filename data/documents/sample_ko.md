# GraphRAG 개요

GraphRAG(그래프 기반 검색 증강 생성)는 지식 그래프의 구조화된 정보와 대규모 언어 모델의 생성 능력을 결합한 차세대 AI 질의응답 시스템입니다.

## 핵심 기술

### 엔티티 해소(Entity Resolution)

엔티티 해소는 서로 다른 데이터 레코드가 동일한 실세계 개체를 가리키는지 판별하는 과정입니다. Senzing SDK는 gRPC 기반 통신을 통해 확장 가능한 엔티티 해소 기능을 제공합니다. 이를 통해 구조화된 데이터에서 중복되거나 유사한 엔티티를 효과적으로 통합할 수 있습니다.

### 지식 그래프

지식 그래프는 엔티티(노드)와 관계(엣지)로 정보를 표현하는 구조입니다. NetworkX는 복잡한 네트워크를 생성, 조작, 분석하기 위한 Python 라이브러리로, 최단 경로 계산, 커뮤니티 탐지, PageRank 기반 엔티티 순위 결정 등 다양한 그래프 연산을 지원합니다.

### 벡터 임베딩

BGE-M3는 BAAI(베이징 인공지능 연구원)에서 개발한 다국어 임베딩 모델입니다. 100개 이상의 언어를 지원하며, 1024차원의 밀집 벡터를 생성합니다. 특히 한국어에 대한 성능이 우수하여 한국어 문서 검색과 유사도 분석에 적합합니다.

### 대규모 언어 모델

Ollama를 통해 로컬에서 실행되는 Gemma 3 27B 모델은 구글이 개발한 다국어 LLM입니다. 27B 파라미터 버전은 복잡한 추론 작업에서 우수한 성능을 보이며, 양자화를 통해 소비자급 GPU에서도 효율적으로 실행할 수 있습니다.

## 파이프라인 구성

GraphRAG 파이프라인은 다음 단계로 구성됩니다:

1. 다양한 소스(워드, 텍스트, 마크다운)에서 문서 수집
2. spaCy와 GLiNER을 활용한 NLP 엔티티 추출
3. NetworkX 기반 지식 그래프 구축
4. LanceDB에 BGE-M3 벡터 임베딩 저장
5. DSPy와 Ollama를 활용한 검색 증강 생성

## 장점

GraphRAG는 기존 RAG 대비 다음과 같은 장점이 있습니다:

- 다단계 추론 질문의 더 나은 처리
- 엔티티 중심의 정확한 응답 생성
- 그래프 기반 맥락을 통한 할루시네이션 감소
- 복잡한 관계 쿼리 지원
- 추적 가능한 지식 경로를 통한 투명성 향상
